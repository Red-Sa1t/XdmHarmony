程序类示例为上游开源项目在 GitHub 发布的正式安装包，体积较大，适合体验多线程下载、暂停与继续。前四个文件由本项目在 GitHub Pages 提供。

建议体验顺序

  1. 依次复制上表地址并开始下载，观察进度窗口中的速度与剩余时间。
  2. 下载程序类安装包时，在列表中点"暂停"，再点"恢复"，下载从中断处继续。
  3. 在"已完成"中查看任务，点左侧"文档、音乐、视频、压缩、程序"分类查看自动归类结果。
  4. 选中一项后点"打开"或"打开目录"；使用搜索、排序、删除；在菜单中查看设置、语言、关于。
