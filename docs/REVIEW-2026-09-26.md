## 四、探针机制设计要点（详见 PROBE_SPEC.md）

- 探针 = 主工程 entry 模块内探针页（probe/ 目录 + ProbeAbility + main_pages 注册），与业务共享 hvigor 门禁。
- 标记契约 `[XDM_PROBE][<单元ID>][<步骤>] key=value`（BEGIN/SUMMARY/END 保留步骤、单行<1500B、只写观测事实不写判定）。
- 判定全部在 `xdm-probe-verify`：确定性正则解析 + 验证 agent 对照期望表四态判定（PASS/FAIL/UNVERIFIED/MISSING）+ fixItems 按 probe-code/business-code/env/doc 分流。
- Phase 0 五项验证映射：U0.2 HTTP（探针主战场）、U0.3 桥服务端（AI 可 curl 自验）+ 扩展侧人工、U0.4 ffmpeg（人工集成+探针验 remux）、U0.1 环境自检、U0.5 调研（AI）+浏览器目检（人工）。
