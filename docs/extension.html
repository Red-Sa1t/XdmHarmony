XDM下载管理器 浏览器扩展安装说明

适用版本：XDM下载管理器 1.0.0；扩展版本 3.3（Manifest V3）

浏览器扩展是可选功能。不安装扩展也可以正常下载：在浏览器中复制下载链接后切回本应用，应用会自动识别剪贴板中的链接并弹出新建下载（也可以点"新建"手动粘贴）。

扩展能做什么

  • 在浏览器中点击下载链接时，把下载交给 XDM下载管理器（多线程、可断点续传）。
  • 网页播放视频时识别视频地址（MP4、HLS、DASH 等），在应用的"媒体抓取"页中选择下载。
  • 可以在扩展弹出窗口中随时关闭接管，关闭后浏览器按原样下载。

安装前准备

  • 已安装并打开 XDM下载管理器（扩展通过本机 127.0.0.1:8597 与应用通信，应用未运行时扩展不会接管下载）。
  • 一款支持"加载已解压的扩展程序"的浏览器（Chromium 内核浏览器通常在扩展管理页提供"开发者模式"）。

本扩展目前没有上架浏览器扩展商店，需要按下面的步骤手动加载。

安装步骤

  1. 下载扩展压缩包：xdm-browser-extension-3.3.zip，解压到一个固定的文件夹（之后不要删除或移动该文件夹）。
  2. 在浏览器地址栏打开扩展管理页（Chromium 内核浏览器一般为 chrome://extensions、edge://extensions 或浏览器菜单中的"扩展程序"）。
  3. 打开页面上的"开发者模式"开关。
  4. 点击"加载已解压的扩展程序"，选择第 1 步解压出的 xdm-browser-extension 文件夹。
  5. 扩展列表中出现"XDM Integration Module"即安装完成。保持 XDM下载管理器运行，并在应用底栏打开"浏览器监视"开关。

数据与隐私

扩展只与本机上的 XDM下载管理器通信，不连接任何外部服务器。接管下载时，扩展会把该下载的地址、文件名以及完成下载所需的请求头（如 Referer、Cookie）发送给本机应用，应用只把这些信息用于向对应的下载服务器发起请求。详见隐私政策。

卸载

在浏览器扩展管理页移除"XDM Integration Module"即可，然后可删除解压出的文件夹。

源代码与许可证

扩展源自开源项目 Xtreme Download Manager（作者 subhra74）的浏览器扩展，按本应用需要做了适配，遵循 GNU 通用公共许可证第 2 版（GPL-2.0）。源代码位于仓库的 extension/ 目录：GitHub · GitCode。
